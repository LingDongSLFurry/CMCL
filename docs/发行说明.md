# Cairn / 石栈 0.1.0 · Java 终端启动器

首次预发布。源码和构建脚本位于本仓库，启动器以命令行字符工作区交互；支持指令、连续指令和脚本，没有图形启动页面。

主要功能包括 Mojang 官方原版下载与补全、Java 管理、隔离实例、六类加载器、Modrinth/CurseForge 资源、整合包、账户协议、后台任务及游戏监护。

支持通过 `source add/edit/check/use/remove` 自定义下载源，分别配置清单、元数据、客户端、库、Assets 和 Java；元数据缓存按源隔离，保留文件哈希校验，登录请求独立。默认仍仅启用 Mojang 官方源，不预置其他镜像。

已完成隔离回归测试，以及真实的原版/加载器下载、文件检查、Sodium 安装、整合包导出导入、官方 Java 与服务端下载。具体版本、测试方式和边界见随包《验证报告.md》。

需要 Java 17+ 运行启动器：

```text
java -jar cairn.jar
```

也可解压完整发行包运行 `Start.cmd`。游戏可使用独立的 Java 8/17/21/25 等运行时。

本版本尚未达到 PCL 全功能完全等价。PCL 私有服务、全部历史兼容补丁及部分原生 Windows 功能未实现；微软授权、CurseForge 密钥、第三方认证、EasyTier 实际联机和真实图形游戏运行尚需对应环境验证。请先阅读功能对照与验证报告。

附件包含可执行 JAR、完整发行包、源码包、中文手册与 SHA-256 校验清单。不包含 Minecraft 游戏文件、JRE、测试账户数据或下载缓存。
