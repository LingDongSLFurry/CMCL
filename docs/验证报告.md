## 尚未验证或未达到等价的部分

没有使用个人微软账户执行在线授权，也没有提供 CurseForge Key、第三方认证服务器账户或 EasyTier 房间/节点，相关代码不能表述为已完成真实服务验证。

真实 Minecraft 图形客户端的渲染、进入世界、音频、显卡驱动、在线服务器登录，以及所有历史版本/加载器/Mod 组合均未实测。子进程夹具通过证明的是进程、参数、日志、凭据处理和状态保存链路。

Linux/macOS、跨平台本地库、各历史整合包变体、皮肤上传与播放硬件未在实际对应环境验证。PCL 的私有服务、全部崩溃特判、窗口操作与兼容补丁未全部实现。

因此，本版本作为预发布交付，不能标为“PCL 全功能 100% 等价版本”。

## 构建与核验

```text
java -jar cairn.jar --version
java -jar cairn.jar --self-test
```

源码中 `build.ps1` / `build.sh` 编译并执行隔离测试。发布文件的 SHA-256 与字节数位于 `checksums.json`。GitHub 发布后另行核对上传大小及公开下载 SHA-256，最终发布记录写入 `publish-receipt.json`。
