# 第三方说明与参考

Cairn / 石栈是独立实现的 Java 终端启动器，非 Mojang、Microsoft 或 PCL 官方产品，没有暗示获得这些项目的认可。

本次按用户指定，将 [Meloong-Git/PCL](https://github.com/Meloong-Git/PCL) 作为功能调查对象。调查快照为 `6b9a50df911c9d68b69b24c979efba477fb14b67`，提交说明为 `2.99.0.0 正式版`，日期 2026-10-20。PCL 作者为龙腾猫跃，赞助链接：https://meloong.com/afd/a/LTCat 。

PCL 仓库的 `LICENCE` 是有限许可及合理使用指南，不是 MIT/GPL 等通用宽松开源许可。Cairn 没有复制 PCL 源码、Logo、XAML 页面、图片、捆绑 JAR 或私有服务配置。功能协议根据各上游公开接口独立实现。源码归档不包含 PCL 仓库。源码符号清单只记录调查路径、声明名称和行号，不能用于还原 PCL 实现。

功能调查也包括该快照固定引用的公开 [MeloongCore](https://github.com/Meloong-Git/MeloongCore) 子模块，提交 `98157d65c7627721c816c02e8be96ac4fe61d615`，其许可为 Apache-2.0。没有复用或分发其代码；符号索引保留参考路径与修订号。

运行时调用的服务：

| 上游 | 用途 | 随包分发 |
| --- | --- | --- |
| Mojang / Microsoft | 版本清单、游戏、库、资源、Java、登录、皮肤 | 不包含游戏或 JRE |
| Fabric / Quilt | 加载器清单和配置 | 不包含 |
| Forge / NeoForge | 官方 Maven 与无界面安装器 | 不包含 |
| OptiFine / LiteLoader | 各自官方下载与安装描述 | 不包含 |
| Modrinth / CurseForge | 社区资源元数据与文件 | 不包含资源或 API 密钥 |

| authlib-injector | 可配置的第三方认证注入器 | 不包含 |

JAR 本身不含第三方依赖库，使用 Java 17 标准 API。启动器运行所需的 JRE/JDK 需自行安装。下载内容的许可与分发限制由各上游决定。
