# Cairn / 石栈 0.1.1

Java 编写的 Minecraft 启动器，只有终端字符界面。提供数字工作区、指令、连续指令、别名、脚本和后台任务。默认仅启用 Mojang 官方源，可以自行添加、检查和切换其他下载源。名称、终端布局和实现独立设计，没有复用 PCL 的界面或代码。

这是具备实际下载与启动能力的实现。请同时阅读《PCL功能与实现对照.md》和《验证报告.md》：本次交付不声称与 PCL 的所有功能、特例补丁和专属服务完全等价。

## 运行

启动器本身需要 **Java 17 或更新版本**。游戏可以单独使用 Java 8、16、17、21 或 25；按版本自动选择，不要求游戏与启动器使用同一个 Java。

Windows 双击 `Start.cmd`，或在终端执行：

```text
java -jar cairn.jar
```

Linux/macOS：

```sh
sh start.sh
```

默认在 JAR 旁的 `cairn-data` 保存数据。可使用环境变量 `CAIRN_HOME` 或显式参数：

```text
java -jar cairn.jar --home "E:\Minecraft\Cairn"
```

启动器不会打开图形页面或浏览器。微软登录时，终端显示网址和设备代码，由使用者在浏览器完成账户授权。真正启动 Minecraft 后，游戏本身正常显示游戏窗口。

## 首次使用

在交互终端输入 `setup`，按提示设置账户、官方版本、实例名和内存。也可直接执行：

```text
account offline Player
install 1.20.1 survival
instance use survival
play
```

离线账户用于本地游戏或允许离线认证的服务器。连接正版服务器应使用持有 Minecraft 的微软账户：

```text
config set msClientId <自己的应用ID>
account microsoft
```

此应用 ID 必须是你有权使用、启用公共客户端/设备代码登录且获准访问 Minecraft 服务的 Microsoft 应用。没有冒用官方启动器或 PCL 的客户端 ID。也可设置环境变量 `CAIRN_MS_CLIENT_ID`。

## 字符工作区

启动后显示独立的终端首页。输入数字进入工作区：

| 输入 | 功能 |
| --- | --- |
| `1` | 实例列表 |
| `2` | 官方版本与下载 |
| `3` | 账户 |
| `4` | Mod、资源和整合包入口 |
| `5` | 后台任务 |
| `6` | 设置 |
| `7` | 环境检查 |
| `8` | 首次配置 |
| `9` | 帮助 |
| `0` | 退出 |

`dashboard` 返回首页；`page instances` 等命令也可直接进入。`config set ascii true` 使用 ASCII 边框；`config set color off` 关闭颜色。自动颜色模式仅在识别到支持 ANSI 的终端时启用。长表格的展示列会截短，`--json` 模式和详情命令保留完整数据。

Windows 控制台编码会自动匹配，避免代码页 936 把 UTF-8 输出显示成“鐭虫爤”等乱码。重定向到管道/文件时默认使用 UTF-8，数据文件也保持 UTF-8。`Start.cmd`、`Start.ps1` 默认切换 UTF-8 并使用 `--plain` 兼容边框，退出后恢复控制台编码。

特殊终端可显式指定编码：

```text
java -jar cairn.jar --encoding GBK
java -jar cairn.jar --encoding UTF-8 --plain
```

显式编码应与终端设置一致；不确定时使用一键脚本。也支持 JVM 属性 `-Dcairn.console.encoding=UTF-8`。`doctor` 会显示当前终端编码和 ANSI 支持情况。

## 指令输入与批处理

路径或名称包含空格时使用引号。单引号中的反斜杠保持字面值，适合 Windows 路径。JSON 数组建议使用外层单引号。

```text
instance describe survival "我的生存世界"
config set jvmArgs '["-Dexample=true"]'
instance set survival java 'D:\Java\jdk17\bin\java.exe'
```

`;` 按顺序执行下一条指令；`&&` 仅在前一条成功时继续。不是操作系统 shell，不执行管道、重定向或 `&` 后台语法。

```text
install 1.20.1 survival && account offline Player && instance use survival
```

耗时操作默认等待完成，因而能安全组合指令。加 `--bg` 才会放入后台：

```text
install 1.21.1 test --bg
tasks
task cancel 1
task wait all
```

单次命令模式退出前会等待后台任务。交互模式可以同时输入查看、取消指令。游戏运行由独立的 Java 监护进程负责，退出启动器后游戏和日志记录可以继续。

单次执行、JSON 输出和脚本：

```text
java -jar cairn.jar --home "E:\Minecraft\Cairn" versions list --type release
java -jar cairn.jar --json instance list
java -jar cairn.jar -c "account offline Player ; versions installed"
java -jar cairn.jar --script workflow.cairn
```

脚本使用 UTF-8，每行一条指令，`#` 开头为注释；遇到失败停止。支持 `${selected}`、`${account}` 和 `${home}` 变量。别名只能表示单条指令，可带固定参数：

```text
alias set go 'play ${selected} --wait'
go
alias list
alias remove go
history
complete inst
```

有 `history` 和指令候选查询；没有需要额外依赖的逐键 Tab 补全或鼠标操作。

## 官方版本、补全与加载器

```text
versions list --type release --limit 20
versions list 1.20 --type snapshot
versions list --offset 20 --limit 20 --refresh
versions installed
versions info 1.20.1
install latest latestGame
install snapshot snapshotGame
repair survival
source list
server download 1.20.1 "E:\Minecraft\server-1.20.1.jar"
```

安装包含客户端、对应操作系统的库、本地库、日志配置、资源索引与资源对象。已正确下载的内容共享复用。官方清单的 SHA-1/大小用于校验；资源下载先写 `.part`，支持断点续传、重试和最终原子提交。

加载器使用其各自上游，与原版游戏的可配置下载源分开：

```text
loader list fabric 1.20.1
loader install fabric 1.20.1 0.16.14 fabricGame
loader install quilt 1.20.1 latest quiltGame
loader list forge 1.20.1
loader install forge 1.20.1 47.4.10 forgeGame
loader install neoforge 1.21.1 latest neoGame
loader install liteloader 1.12.2 latest liteGame
loader list optifine 1.20.1
loader install optifine 1.20.1 latest optifineGame
loader local optifine "E:\Downloads\OptiFine_1.20.1_HD_U_I6.jar" 1.20.1 optifineLocal
```

Fabric/Quilt 使用上游版本描述。Forge/NeoForge 调用官方安装器的 `--installClient`；旧安装器是否支持此参数取决于其上游实现。OptiFine 使用官网页面及公开安装入口；网站变化时可改用本地官方安装器。所有安装器强制无界面执行，失败后会保留日志，不退回图形安装。

Fabric API 等配套 Mod 通过 `content install fabric-api` 安装。已有 Forge 实例需要将兼容的 OptiFine 作为 Mod 使用时，可通过本地 Mod 导入指令安装；不会自动判断所有 Forge/OptiFine 组合的兼容性。

## 实例和外部游戏目录

```text
instance list
instance use survival
instance info survival
instance paths survival
instance create another 1.20.1
instance clone survival copied --saves
instance rename copied copied2
instance describe survival "生存服"
instance star survival
instance hide survival
instance list --all
instance show survival
instance remove copied2
trash list
trash restore <回收项名称>
```

默认游戏数据按实例隔离，共享版本、库和资源。`instance remove` 仅把该实例移到回收区，共享下载保留。删除游戏内容、清缓存等也进入回收区；暂不提供永久清空回收区的指令。

读取和导入已有 `.minecraft`：

```text
root add old "D:\Games\.minecraft"
root list
root versions old
root adopt old 1.20.1-forge-47.4.10 imported
```

`root adopt` 复制所需描述、库及该版本隔离目录中的常见游戏内容，并补全所需文件；原目录不写入。不会导入原启动器的账户密钥。共享库或同 ID 版本发生内容冲突时拒绝覆盖。

## 账户和皮肤

```text
account list
account use Player
account refresh
account remove offline-Player
account auth https://example.com/api/yggdrasil/ email@example.com
account nide <服务器ID> <用户名>
config set authlibInjector 'E:\Tools\authlib-injector.jar'
skin download Player 'E:\Pictures\skin.png'
skin download self 'E:\Pictures\my-skin.png'
skin set-url classic https://example.com/skin.png
skin set-url slim https://example.com/skin.png
skin upload classic 'E:\Pictures\my-skin.png'
skin reset
skin offline 'E:\Pictures\skin.png' survival
```

第三方认证密码由终端隐藏输入；重定向到管道时从标准输入读取。第三方账户启动需要另行提供合法的 authlib-injector。统一通行证是对应 Yggdrasil 服务地址的适配，需要该服务继续支持此协议。

本地皮肤通过资源包替换默认人物贴图，仅本机可见；不同游戏版本存在兼容提示，不能替代正版账户的联网皮肤。PNG 须为 64×32 或 64×64，保留原 `options.txt` 的备份。

账户和刷新令牌使用 AES-256-GCM 保存，密钥文件与密文限制为当前用户读取。它能减少误读和其他本地用户访问，不能防御已取得当前用户权限的程序。不要把整个数据目录作为公开压缩包分享。

## Java、内存、窗口与参数

```text
java scan
java add 'D:\Java\jdk21'
java use auto
java for survival
java available
java install 21
config set memoryMiB 4096
config set minMemoryMiB 512
config set width 1280
config set height 720
config set fullscreen false
config set gc g1
instance set survival memoryMiB 6144
instance set survival gc zgc
instance set survival gameArgs '["--example","value"]'
instance reset survival memoryMiB
memory
```

`gc` 支持 `g1`、`zgc`、`none`。只为兼容的 Java 添加分代 ZGC 参数。最大内存必须不小于最小内存，32 位 Java 不允许分配过高内存。

`before`/`after` 是单个进程的参数数组：

```text
instance set survival before '["E:\\Tools\\prepare.exe","--instance","survival"]'
instance set survival after '["E:\\Tools\\backup.exe","--quick"]'
```

直接使用进程参数启动，不经过系统 shell，单个钩子最多运行 5 分钟。导入整合包不启用包中携带的启动钩子。

`isolation` 可全局或按实例设置。切换隔离不会自动移动旧存档；请先查看游戏目录，并根据需要复制数据。

## 游戏、日志和诊断

```text
play survival
play survival --wait
play survival --dry-run
play survival --server example.org:25565
play survival --no-repair --no-java-download
sessions
logs survival --lines 100
logs survival --follow
stop survival
stop all --force
launch-script survival 'E:\Minecraft\play-survival.cmd'
doctor survival --deep
crash survival
crash --file 'E:\Minecraft\crash-report.txt'
report survival 'E:\Minecraft\diagnostic.zip'
```

默认启动前补全文件，自动缺省选用对应 Java；缺少自动选择的 Java 时下载 Mojang 官方运行时。`--dry-run` 不启动游戏、不刷新登录，但会准备本地库及旧版虚拟资源。

参数预览、启动脚本和监护日志不写出账户令牌。导出的脚本只会再次调用启动器，在启动时获取有效账户，不固化过期令牌。诊断为带证据的规则匹配，不保证识别所有崩溃原因。

## Mod、光影、资源包和数据包

```text
content search sodium --type mod --game 1.20.1 --loader fabric
content info sodium
content versions sodium --game 1.20.1 --loader fabric
content install sodium --instance fabricGame
content install fabric-api --instance fabricGame
content search Complementary --type shader
content install <项目ID> --type shader --instance fabricGame
content install <数据包项目ID> --type datapack --instance survival --world MyWorld
content import mod 'E:\Downloads\example.jar' --instance fabricGame
content import resourcepack 'E:\Downloads\textures.zip' --instance survival
content update fabricGame
content update fabricGame --apply
content remove mod example.jar --instance fabricGame
mod list fabricGame
mod disable example.jar --instance fabricGame
mod enable example.jar.disabled --instance fabricGame
mod check fabricGame
```

Modrinth 为默认资源平台。按实例游戏版本、加载器选择版本，安装必须依赖，保存内容锁定清单；不自动安装可选依赖。更新默认预览，使用 `--apply` 才替换，旧文件进入回收区。手动修改过的受管理文件不会被静默覆盖。

CurseForge：

```text
config set curseforgeKey
content search sodium --source curseforge --game 1.20.1
content install <数字项目ID> --source curseforge --instance fabricGame
```

API Key 通过隐藏输入加密保存，亦支持 `CAIRN_CF_KEY` 环境变量。作者禁止第三方分发的文件不会绕过限制，需要按项目页说明手动下载再导入。

Mod 启停是 `.jar` 与 `.jar.disabled` 的安全重命名，记录的元数据支持 Fabric、Quilt、Forge/NeoForge 和旧版 `mcmod.info`。重复 ID 检查不等同于完整 Mod 依赖求解器。

## 整合包

```text
pack import 'E:\Downloads\example.mrpack' packGame
pack import 'E:\Downloads\curseforge-pack.zip' cfGame
pack fetch <项目ID> downloadedPack
pack fetch <数字项目ID> cfPack --source curseforge
pack export survival 'E:\Minecraft\my-pack.zip'
pack export survival 'E:\Minecraft\my-pack-with-saves.zip' --saves
```

支持识别 Modrinth、CurseForge、MultiMC/Prism、MCBBS、HMCL、Cairn 及标准游戏目录压缩包。各生态存在历史变体；特别是没有标准描述的多版本目录压缩包会要求先拆分，避免猜错启动配置。

Cairn 导出包含游戏配置、Mod、必要加载器描述与库；默认不含存档、游戏日志、崩溃日志、账户和访问令牌。导入时从 Mojang 获取原版客户端和资源，不导出启动器的凭据。包内配置、服务器地址和 Mod 自身可能保存个人信息，分享前请检查。

## 联机、服务器状态和本地音频

```text
server ping example.org:25565
lan --seconds 3
config set easyTier 'E:\EasyTier\easytier-core.exe'
link host myroom tcp://your-node.example:11010 --port 25565
link join myroom tcp://your-node.example:11010 --port 25565
link status
link log
link stop
music play 'E:\Music\background.wav' --volume 0.4
music stop
```

EasyTier 使用你提供的程序和节点，不使用 PCL 的私有节点目录。双方需使用相同房间名、密码、节点及游戏端口。房主须先在 Minecraft 中开放局域网；不同系统的网络驱动和权限要求由 EasyTier 决定。房间密码从终端隐藏输入；底层工具的进程参数可能被同权限系统工具查看。

局域网发现监听 Minecraft 组播广播；服务器状态使用 Java 版状态协议。当前地址查询不自动解析 Minecraft SRV 记录。

内置音频使用 JRE 的 WAV/AIFF/AU 解码，不包含 MP3/OGG 插件；音乐仅在交互启动器进程运行时播放。

## 下载和配置

下载源默认只有只读的 `official`，不预置第三方镜像。可以通过指令自行配置：

```text
source list
source add myMirror https://mirror.example.org
source edit myMirror --libraries https://mirror.example.org/maven
source edit myMirror --assets https://mirror.example.org/assets
source check myMirror
source show myMirror
source use myMirror
source use official
source remove myMirror
```

示例域名须换成实际服务地址。基础地址需要兼容 Mojang URL 的路径；程序不会猜测某个镜像服务的 API 格式。也可独立覆盖这些字段：

| 选项 | 含义 |
| --- | --- |
| `--manifest` | 完整 `version_manifest_v2.json` URL |
| `--metadata` | 游戏版本、Assets 索引等元数据基础地址 |
| `--client` | 客户端、服务端、日志配置文件的基础地址 |
| `--libraries` | 原 `libraries.minecraft.net` 对应的基础地址 |
| `--assets` | 资源对象基础地址，之后追加 `ab/完整哈希` |
| `--java-index` | 完整 Mojang 兼容 Java 索引 URL |
| `--java-metadata` | Java 运行时文件清单的基础地址 |
| `--java-files` | Java 运行时文件下载基础地址 |

例如，原 URL `/v1/objects/<hash>/client.jar` 会追加到 `--client` 指定的基础地址；库的原路径是 `/com/example/...`，资源原路径是 `/ab/hash`。如果服务需要 `/maven`、`/assets` 前缀，请在对应基础地址中加入。

`source edit 名称 新基础地址` 会重建该源的默认映射；只传覆盖选项则保留其余字段。下载等后台任务运行时不能修改或切换源。元数据缓存按源和配置内容隔离，已有客户端、库及资源继续按哈希复用。配置导入导出包含自定义源。

`source check` 只验证版本清单、样本版本描述和提供的描述哈希，不等于验证了所有下载端点。文件仍按所选清单的哈希验证；选择自定义源意味着信任它提供的元数据，不应把哈希校验解释为 Mojang 对镜像清单的签名认证。

默认要求 HTTPS；如果是自己的局域网 HTTP 服务，显式启用：

```text
source add local http://127.0.0.1:8080 --allow-http
```

HTTP 仅允许配置范围内的地址，HTTPS CDN 重定向可用。基础地址不接受内嵌用户名/密码、查询参数或片段。下载源不改写微软/Yggdrasil 登录请求，也不切换 Modrinth/CurseForge 等社区平台；`content --source` 仍用于选择资源平台。

```text
config set threads 8
config set retries 3
config set speedKiB 2048
config set proxy http://127.0.0.1:7890
config export 'E:\Minecraft\cairn-settings.json'
config import 'E:\Minecraft\cairn-settings.json'
cache info
cache clean
news --refresh
about
features
help all
```

代理也识别 `HTTPS_PROXY` / `https_proxy`。改变配置中的代理需重启；切换下载源即时生效。不会关闭 TLS 证书验证。`speedKiB=0` 表示不限速；设置上限时使用单个下载工作线程，以保证总速率上限。

完整指令帮助在 `完整指令.txt`，也始终内置于 JAR 的 `help all`。源码归档内提供 Windows/Linux 构建脚本，JDK 17 即可编译，不依赖 Maven、Gradle 或外部运行库。
